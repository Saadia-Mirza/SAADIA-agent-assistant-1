## Tips

- Plain-text (`.md`, `.txt`) is read most reliably. If your source files are
  `.pdf` or `.docx`, you can upload them as-is, but pasting the key content into
  a Markdown file here gives the cleanest results.
- Use clear file names, e.g. `4.2-document-management.md`.
